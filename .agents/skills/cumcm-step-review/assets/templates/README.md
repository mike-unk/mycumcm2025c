
# 国赛论文 LaTeX 模板

本目录存放全国大学生数学建模竞赛论文的 **2026 版 LaTeX 模板**。

模板以 2026 年竞赛论文格式要求为依据，用于生成数学建模竞赛论文。使用时应以本目录中的模板文件为准，不再将其视为“构建基线”或官方模板缺失情况下的替代方案。

## 模板内容

当前目录主要包含：

* `main.tex`：论文主文件及 LaTeX 模板示例
* `references.bib`：参考文献数据库示例
* `论文模板.docx`：Word 论文模板
* 其他 `.cls`、`.sty` 等 LaTeX 模板依赖文件

LaTeX 模板已经按照 2026 版论文格式进行整理，包括论文首页、摘要、正文、参考文献及附录等结构。

## 使用说明

### 1. LaTeX 模板

以 `main.tex` 为入口文件，根据实际论文内容替换模板中的标题、摘要、关键词、正文、参考文献等内容。

推荐使用 **XeLaTeX** 编译：

```bash
xelatex main.tex
bibtex main
xelatex main.tex
xelatex main.tex
```

如果论文内容或参考文献发生修改，建议重新执行完整编译流程。

如果项目提供了对应的 LaTeX 工具链，应优先使用工具链提供的编译、检查和验收功能。

### 2. 占位符

模板中的部分内容使用 `LATEX_TEMPLATE_*` 作为占位符，例如：

* `LATEX_TEMPLATE_TITLE`
* `LATEX_TEMPLATE_ABSTRACT`
* `LATEX_TEMPLATE_KEYWORDS`
* 其他正文占位内容

正式编译前应将所有占位符替换为实际论文内容。

不要直接提交仍包含 `LATEX_TEMPLATE_*` 占位符的论文。

## 论文结构

2026 版模板对应的论文内容按照以下结构组织：

1. 摘要
2. 问题重述
3. 问题分析
4. 模型假设与符号说明
5. 数据预处理
6. 逐问建模与求解
7. 模型的分析与检验
8. 模型的评价与推广
9. 参考文献
10. 附录

其中附录用于放置论文相关支撑材料，包括：

* 支撑材料文件列表
* 完整、可运行的源程序
* 其他需要提交的辅助材料

具体论文格式、页数、提交方式等要求应以当届竞赛发布的官方文件为准。

## 与 Word 模板的关系

本目录同时提供 LaTeX 和 Word 两种论文模板。

两种模板用于生成符合竞赛论文格式要求的论文，但正文内容应保持一致。修改论文内容时，应避免 Word 与 LaTeX 两份正文长期独立维护，以免产生内容不一致。

## 编译与检查

完成论文后，建议依次进行：

1. 检查模板占位符是否全部替换；
2. 编译 LaTeX；
3. 检查交叉引用、公式、图片和参考文献；
4. 检查页码、页眉页脚、字体、字号及页面布局；
5. 检查摘要页和正文页数；
6. 检查附录中的支撑材料及完整源程序；
7. 对最终生成的 PDF 进行完整验收。

项目中的相关脚本和工具可用于辅助检查，但最终提交前仍应以当届竞赛官方要求和最终生成文件为准。
